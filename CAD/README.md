# CAD

Parametric model of the rover chassis in OpenSCAD, plus exported STLs.

* `RESQ_ROVER_V12.scad` - the master model. Tune wheelbase, plate thickness and mount holes here, re-export the plates after any change.
* `plate_1_base.stl` - bottom plate. Prints flat, no supports needed.
* `plate_2_upper.stl` - top plate that carries the kit cradle.
* `plate_3_hardware.stl` - motor mounts, sensor brackets and standoffs.

Wide-track 215 x 215 mm base. Everything is support-free and fits a standard 220 mm bed.
